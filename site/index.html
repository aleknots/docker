Docker Labs Nginx

Static web server

Nginx servindo um site estático em container

Um lab simples para praticar volume bind, porta publicada e execução com Docker Compose.

Imagem oficial

Usa `nginx:1.27-alpine`, uma imagem leve e comum para servir arquivos estáticos.

Volume read-only

Os arquivos locais são montados no container sem permissão de escrita.

Porta local

O Nginx fica disponível em `http://localhost:8080`.
